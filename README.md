# 睿非科技研發專案與發想路線全景 (Reaify Tech RF_Log)

東方水墨風 (Ink Wash Aesthetic) 研發知識庫與動態路線視覺導覽平台。

## ✨ 特色與美學亮點

- **東方水墨視覺語言 (Ink Wash Aesthetic)**：宣紙底色 (`#F4F1EA`) 結合水墨濃墨氣場與濃淡暈染效果。
- **動態物理核心 (Inertial Fluid Core)**：
  - 核心水墨黑球具有 **宣紙濃墨韻味 (Pure Ink Wash Cloud)** 視覺，搭配純白標誌 `"R"`。
  - **100% 同心幾何鎖定與呼吸連動**：黑球呼吸起伏時，"R" 標誌 100% 同步漲縮。
  - **慣性方向性拉伸變形 (Speed Directional Fluid Stretch)**：拖拽時沿運動方向動態拉伸壓扁。
  - **Q 彈果凍回彈 (Fluid Release Bounce)**：放手時呈現柔軟平滑的水墨彈性復原。
- **簡稱區分與智慧 Tooltip (Disambiguated Keywords & Smart Placement)**：
  - 專案標籤具備唯一區分度（如 `TRPG語`, `TRPG影`）。
  - 全名 Tooltip 外側向上彈出，絕不遮擋周圍節點。
