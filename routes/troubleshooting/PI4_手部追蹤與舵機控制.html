01 🤖 給 AI 下達的超級 Prompt 範本

你是一位專精於 Raspberry Pi (Pi4)、電腦視覺 (OpenCV + MediaPipe Hands) 與嵌入式硬體控制 (pigpio) 的高級系統架構師。

請協助我開發一個「MediaPipe 手辨識追蹤與 pigpio 零抽搐舵機控制系統」。在撰寫程式碼時，你必須嚴格遵守以下防踩坑規範：

1. 硬體 PWM 與零通電微震規範：
   - 嚴禁使用 RPi.GPIO 的軟體 PWM（Linux 排程誤差引發抽搐）。
   - 必須使用 pigpio 硬體 DMA PWM，時脈誤差 < 1μs。
   - 支援 0μs 訊號切斷保護 (Pulse Cutoff)，靜止時執行 set_servo_pulsewidth(pin, 0) 徹底放鬆馬達。

2. CW/CCW 獨立起步阻力與雙門檻遲滯：
   - 獨立起步脈衝門檻：MIN_MOVE_PW_CW=40, MIN_MOVE_PW_CCW=55，補償摩擦阻力不對稱。
   - 雙門檻死區遲滯：進入死區 ENTER=0.14，離開死區 EXIT=0.18，防止邊界急啟急煞。

3. 視覺推論與 OneEuroFilter 防抖：
   - model_complexity=0 (Lite)，解析度 320x240。
   - 手掌質心取手腕(0) + 四指根(5,9,13,17) 算術平均。
   - 套用 OneEuroFilter (min_cutoff=0.8, beta=0.4)。
   - 移動時單手對齊追蹤，煞停後才辨識雙手 1~99 數字。

02 🏆 黃金標準參考代碼 (Golden Reference)

import time, math, threading
import numpy as np, cv2, mediapipe as mp, pigpio
from loguru import logger

SERVO_PIN       = 18
STOP_PW         = 1470
MIN_MOVE_PW_CW  = 40
MIN_MOVE_PW_CCW = 55
MAX_MOVE_PW     = 120
TRACK_SIGN      = -1

CENTER_TOLERANCE_ENTER = 0.14
CENTER_TOLERANCE_EXIT  = 0.18
PALM_INDEXES           = [0, 5, 9, 13, 17]

class ServoModule:
    def __init__(self, pin: int = SERVO_PIN, stop_pw: int = STOP_PW):
        self.pin = pin
        self.stop_pw = stop_pw
        self._lock = threading.Lock()
        self._last_pw = stop_pw
        self._is_motor_stopped = True

        self.pi = pigpio.pi()
        if not self.pi.connected:
            raise RuntimeError("pigpiod 未啟動，請執行: sudo systemctl start pigpiod")
        
        self.pi.set_servo_pulsewidth(self.pin, 0)
        self._last_pw = 0

    def set_pw(self, pw: int):
        with self._lock:
            if pw == 0:
                if self._last_pw != 0:
                    self.pi.set_servo_pulsewidth(self.pin, 0)
                    self._last_pw = 0
                return
            pw_clamped = max(1000, min(2000, pw))
            if abs(pw_clamped - self._last_pw) >= 2:
                self.pi.set_servo_pulsewidth(self.pin, pw_clamped)
                self._last_pw = pw_clamped

    def compute_target_pw(self, offset: float) -> int:
        abs_off = abs(offset)
        if self._is_motor_stopped:
            if abs_off <= CENTER_TOLERANCE_EXIT:
                return self.stop_pw
            self._is_motor_stopped = False
        else:
            if abs_off <= CENTER_TOLERANCE_ENTER:
                self._is_motor_stopped = True
                return self.stop_pw

        eff_offset = abs_off - CENTER_TOLERANCE_ENTER
        ratio = min(1.0, eff_offset / (0.5 - CENTER_TOLERANCE_ENTER))
        direction = TRACK_SIGN * (1 if offset > 0 else -1)
        min_pw = MIN_MOVE_PW_CW if direction > 0 else MIN_MOVE_PW_CCW
        add_pw = min_pw + ratio * (MAX_MOVE_PW - min_pw)
        return int(self.stop_pw + direction * add_pw)

    def cleanup(self):
        self.set_pw(0)
        self.pi.stop()

03 ⚡ 硬體架構與防踩坑規範

1. 獨立 5V/3A 變壓器供電

舵機瞬間電流可達 2A，嚴禁直接由樹莓派 5V 引腳供電（否則瞬間壓降引發當機）。馬達電源 GND 必須與樹莓派 GND 共地。

2. GPIO 18 音訊衝突避開

GPIO 18 (PWM0) 與 3.5mm 耳機孔共用硬體時脈。若需播放語音，PWM 控制腳位需改用 GPIO 12 或 GPIO 13。

04 🖐️ MediaPipe 21 點手勢判斷與數字辨識

手勢判定透過計算各指尖（Tip）與指根（MCP）之相對歐氏距離進行開闔檢測。煞停後自動將畫面中由左至右之兩隻手組合為十位數與個位數（1~99）。

99 號特徵手勢：拇指指尖與食指指尖閉合形成圓圈，中指、無名指與小指伸直即判定為 OK 手勢 (99)。
