OpenCV 內參標定

相機鏡頭去畸變棋盤格標定教學流程 SOP

適用於手部追蹤鏡頭在真實環境使用前的一次性標定，解決廣角/魚眼鏡頭邊緣壓縮與座標變形問題。

📋 一、 前置準備

1
下載棋盤格圖案

從 OpenCV 官方下載標準棋盤格（黑白格）圖案，推薦使用 9×6 內角點版本。

2
列印並固定於硬板

用 A4 紙列印並貼在平整硬紙板或木板上，確保完全平整，不能有翹曲或摺痕。

3
確認內角點數量

注意是「內角點」數量，非格子數（例如 10×7 格的棋盤格，內角點為 9×6）。

📸 二、 拍攝規則表

項目 要求與規範
拍攝環境 任意平坦、光線充足的地方即可。
使用鏡頭 必須使用實際要部署的那顆攝影機（換鏡頭需重新標定）。
解析度設定 跟正式程式的 frame_width / frame_height 完全一致（如 320x240 或 640x480）。
拍攝張數 15~25 張。
位置分佈 棋盤格需出現在畫面左上、右上、左下、右下與中央，包含正拍、傾斜與遠近。

💻 三、 執行標定程式 (Python)

import cv2
import numpy as np
import glob

CHECKERBOARD = (9, 6)  # (列, 欄) 內角點數
SQUARE_SIZE = 2.5       # 每格實際邊長 (cm)

objp = np.zeros((CHECKERBOARD[0] * CHECKERBOARD[1], 3), np.float32)
objp[:, :2] = np.mgrid[0:CHECKERBOARD[0], 0:CHECKERBOARD[1]].T.reshape(-1, 2)
objp *= SQUARE_SIZE

objpoints, imgpoints = [], []
images = glob.glob("calib_images/*.jpg")

for fname in images:
    img = cv2.imread(fname)
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    ret, corners = cv2.findChessboardCorners(gray, CHECKERBOARD, None)

    if ret:
        objpoints.append(objp)
        corners_refined = cv2.cornerSubPix(
            gray, corners, (11, 11), (-1, -1),
            criteria=(cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.001)
        )
        imgpoints.append(corners_refined)

ret, mtx, dist, rvecs, tvecs = cv2.calibrateCamera(
    objpoints, imgpoints, gray.shape[::-1], None, None
)

print(f"標定完成！重投影誤差 (RMS): {ret:.4f} 像素")
np.savez("camera_calib.npz", mtx=mtx, dist=dist)
print("已儲存相機參數至 camera_calib.npz")

🔌 四、 主程式去畸變整合

在正式追蹤程式中載入 camera_calib.npz，在每幀影像讀取後呼叫 cv2.undistort：

calib = np.load("camera_calib.npz")
mtx, dist = calib["mtx"], calib["dist"]

# 在主相機迴圈中：
ret, frame = cap.read()
frame_undistorted = cv2.undistort(frame, mtx, dist)
