影像辨識 TRPG 輔助系統 (CV-TRPG)
工程落地與架構指南

將電腦視覺 (Computer Vision) 引入傳統實體桌遊 (D&D, CoC)。自動化處理移動步數計算、動態視線判定 (LoS) 與戰術迷霧揭露，同時保留實體棋子與擲骰的手感體驗。

1. 核心應用功能模組 (Core System Modules)

🎯 戰局自動化 (Tactical & FoW)

  • 自動步數與移動邊界：追蹤棋子底座，計算移動距離（如 30 呎/6 格），超越限制時紅框提示。
  • 動態戰略迷霧：依據角色棋子座標與視線 (LoS)，即時揭露投影地圖的未知區域。
  • 掩體與視線判定：自動繪製棋子射線與牆壁障礙求交點，判定半/全掩蔽。
  • 威脅範圍判定：敵方棋子離開角色控制格時觸發借機攻擊提示。

🃏 實體道具與手勢 (Props & Gestures)

  • 道具卡與卷軸感應：感應區辨識實體裝備卡/藥水瓶，自動播放背景法術與吟唱音效。
  • 手勢法術繪製：結合手部關鍵點偵測 (Hand Tracking)，玩家在空中劃出指定符文軌跡即可觸發高階法術。

🎲 擲骰結果結算 (Dice Automation)

  • 多骰面自動識別：自動偵測托盤內骰子種類 (d4~d20) 與頂面點數。
  • 自動加成計算：讀取數位角色卡，自動加總力量/敏捷修正值並顯示判定結果。

2. 系統技術架構與視覺拓撲 (Architecture Topology)

功能模組 推薦技術 Stack 工程選用理由
影像預處理 OpenCV Python / C++ 執行單應性矩陣 (Homography) 透視校正、區域裁切 (ROI)、光線降噪。
棋子 / 標籤定位 ArUco Markers / AprilTag 極推薦。算力需求極低（單板機即可跑滿 60 FPS），能精準獲取 ID、座標與角度。
無標籤物件辨識 YOLOv8 / YOLOv11 Nano 用於辨識骰子點數、客製化未貼標籤的怪獸模型。
手勢與符文識別 MediaPipe Hand Landmarker 即時抓取手部 21 個關鍵點，輕量且機能穩定。

3. 關鍵工程挑戰與解決方案 (Engineering Challenges)

🛠️ 挑戰一：玩家手部遮擋導致棋子「閃爍/消失」(Occlusion)

  • 狀態機設計：為棋子建立 Active (活躍)、Occluded (被遮擋)、Removed (已移出) 三種狀態。
  • 緩衝平滑化：標籤消失時轉為 Occluded，啟動 1.5 秒 Debounce Timer。利用卡爾曼過濾器 (Kalman Filter) 預測位置，維持地圖畫面穩定。
  • 終點鎖定：標籤消失超過 1.5 秒且無手部輪廓時才判定為 Removed。

🛠️ 挑戰二：桌面投影光線干擾影像辨識 (Optical Feedback Loop)

  • 硬體隔離解法：使用 850nm 紅外線 LED 補光燈 照射桌面，鏡頭加裝 850nm Narrowband Pass Filter。
  • 光學原理：投影機發出的可見光無法穿過 850nm 濾鏡，動態彩色地圖在鏡頭中完全隱形，只保留清晰的 ArUco 黑白標籤。

4. 基礎開發實作範例 (OpenCV + ArUco 定位)

import cv2
import cv2.aruco as aruco
import json
import time

# 初始化 ArUco 字典與檢測器
aruco_dict = aruco.getPredefinedDictionary(aruco.DICT_4X4_50)
parameters = aruco.DetectorParameters()

# 增強低光環境下的檢測能力
parameters.adaptiveThreshWinSizeMin = 3
parameters.adaptiveThreshWinSizeMax = 23
parameters.adaptiveThreshWinSizeStep = 10

detector = aruco.ArucoDetector(aruco_dict, parameters)
cap = cv2.VideoCapture(0)

print("[CV-TRPG] 棋子追蹤系統啟動中...")

while True:
    ret, frame = cap.read()
    if not ret: break

    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    corners, ids, rejected = detector.detectMarkers(gray)
    tracking_data = []

    if ids is not None:
        aruco.drawDetectedMarkers(frame, corners, ids)
        for i, marker_id in enumerate(ids):
            c = corners[i][0]
            center_x = int((c[0][0] + c[2][0]) / 2)
            center_y = int((c[0][1] + c[2][1]) / 2)
            
            tracking_data.append({
                "id": int(marker_id[0]),
                "x": center_x,
                "y": center_y,
                "timestamp": time.time()
            })

    cv2.imshow("CV-TRPG Tracker View", frame)
    if cv2.waitKey(1) & 0xFF == ord('q'): break

cap.release()
cv2.destroyAllWindows()
