二、完整接線規劃（Net List）

Net接線方式
Net_5V_MAINIP5328P 5V → MaixCAM VBUS → WS2812 VCC → 470µF → Ferrite Bead
Net_5V_DIRTYFerrite Bead → 470µF → 0.1µF → MG90S VCC
Net_GND所有模組共地，Servo 回流避免穿越 MCU 區域
UART_TXMaixCAM GPIOA18 → 22Ω → RP2040 GP0
UART_RXRP2040 GP1 → 22Ω → MaixCAM GPIOA19
Servo PWMMaixCAM GPIOA17 → 100Ω → MG90S PWM
LED DINRP2040 GP15 → 470Ω → WS2812 DIN
I²C0GP4 SDA → PN532 SDA；GP5 SCL → PN532 SCL（各 4.7kΩ Pull-up）
I²C1GP6 SDA → AS5600 SDA；GP7 SCL → AS5600 SCL（各 4.7kΩ Pull-up）
SpeakerMaixCAM VOP → SPK+；MaixCAM VON → SPK−（不可接 GND）
3.3VMaixCAM 3.3V 不外接；RP2040 使用自身 3.3V 供電
