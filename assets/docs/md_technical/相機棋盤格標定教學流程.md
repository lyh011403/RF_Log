# 相機鏡頭去畸變標定教學流程

適用於：手部追蹤鏡頭在真實環境使用前的一次性標定（解決廣角/魚眼鏡頭邊緣壓縮變形問題）。

---

## 前置準備

1. **下載棋盤格圖案**：從 OpenCV 官方文件下載標準棋盤格（黑白格）圖案，例如 9×6 內角點的版本。
2. **列印並固定**：用 A4 紙印出來，貼在硬紙板或木板上,確保完全平整、格線是直線，不能有翹曲或摺痕。
3. **記錄內角點數**：注意是「內角點」數量，不是格子數（例如 10×7 格的棋盤格，內角點是 9×6）。之後程式要對應輸入這個數字。

---

## 拍攝規則

| 項目 | 要求 |
|---|---|
| 拍攝環境 | 任意平坦、光線充足的地方即可，不用是正式部署的桌遊桌 |
| 使用鏡頭 | 必須用實際要部署的那顆攝影機，換鏡頭要重新標定 |
| 解析度設定 | 跟正式程式的 `frame_width` / `frame_height` 完全一致 |
| 拍攝張數 | 15~25 張 |
| 位置分佈 | 棋盤格要出現在畫面**各個角落**（左上、右上、左下、右下、中央都要有），只拍中央沒用 |
| 角度變化 | 正拍、左右傾斜、上下傾斜、拉近拉遠都要各拍幾張，不能每張角度都一樣 |
| 對焦 | 確保每張棋盤格都清晰對焦，模糊的照片會讓標定結果失準 |

拍攝方式兩種都可以：棋盤格固定不動、拿鏡頭移動拍；或鏡頭固定、拿棋盤格移動拍。效果相同。

---

## 執行標定程式

```python
import cv2
import numpy as np
import glob

# ── 設定：填你的棋盤格內角點數 ─────────────────────
CHECKERBOARD = (9, 6)  # (列, 欄) 內角點數，依實際棋盤格調整
SQUARE_SIZE = 2.5       # 每格實際邊長（公分），影響外參尺度，不影響去畸變本身

# 準備世界座標系的角點座標 (z=0 平面)
objp = np.zeros((CHECKERBOARD[0] * CHECKERBOARD[1], 3), np.float32)
objp[:, :2] = np.mgrid[0:CHECKERBOARD[0], 0:CHECKERBOARD[1]].T.reshape(-1, 2)
objp *= SQUARE_SIZE

objpoints = []  # 世界座標點
imgpoints = []  # 對應的影像座標點

images = glob.glob("calib_images/*.jpg")  # 拍好的照片放這個資料夾

for fname in images:
    img = cv2.imread(fname)
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    ret, corners = cv2.findChessboardCorners(gray, CHECKERBOARD, None)

    if ret:
        objpoints.append(objp)
        corners_refined = cv2.cornerSubPix(
            gray, corners, (11, 11), (-1, -1),
            criteria=(cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.001)
        )
        imgpoints.append(corners_refined)
        print(f"[OK] {fname} 偵測到棋盤格")
    else:
        print(f"[跳過] {fname} 未偵測到棋盤格，檢查是否模糊或角度太斜")

# 執行標定
ret, camera_matrix, dist_coeffs, rvecs, tvecs = cv2.calibrateCamera(
    objpoints, imgpoints, gray.shape[::-1], None, None
)

print("標定完成，重投影誤差（越接近 0 越好）:", ret)
print("Camera Matrix:\n", camera_matrix)
print("Distortion Coefficients:\n", dist_coeffs)

# 存檔，正式運行時直接載入，不用每次重新標定
np.savez("camera_calib.npz", camera_matrix=camera_matrix, dist_coeffs=dist_coeffs)
```

**檢查標定品質**：`ret` 是重投影誤差（reprojection error），數值越接近 0 代表標定越準，一般建議在 0.5 以內算合格。如果誤差偏高，通常是某幾張照片模糊或棋盤格沒對齊，可以刪掉誤差大的那幾張重跑。

## 正式運行時套用

```python
import numpy as np
import cv2

calib = np.load("camera_calib.npz")
camera_matrix = calib["camera_matrix"]
dist_coeffs = calib["dist_coeffs"]

# 每一幀做去畸變（在原本 process_frame 最前面加這行）
def undistort_frame(frame):
    return cv2.undistort(frame, camera_matrix, dist_coeffs, None, camera_matrix)
```

放在 `process_frame()` 一開始、`cv2.flip()` 之前執行，之後所有的手部偵測、offset 計算都會基於已經校正過的畫面，不再受廣角邊緣壓縮影響。

---

## 什麼時候需要重新標定

- 換了不同的攝影機/鏡頭
- 改變了程式裡設定的解析度（`frame_width`/`frame_height`）
- 手動調整過鏡頭的變焦/對焦環（如果鏡頭可調焦距）

只要上述三項都沒變，這組 `camera_calib.npz` 可以一直沿用，不用每次開機重跑。

---

## 與後續步驟的關係

此教學只處理**鏡頭本身的光學畸變**。下一步的「桌面透視校正（homography 攤平）」是另一個獨立階段，需要在正式安裝好的環境量測桌子四個角的像素座標，跟這次的鏡頭標定不是同一件事，也不需要同時做。建議順序：先完成這份鏡頭標定 → 確認去畸變效果 → 再進行桌面透視校正。
